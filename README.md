# Fireworks
My inventory system code for a Game Jam Project 
SCR_PlayerInventory = opening and closing players inventory and crafting UI
SCR_Inventory = Functions for inventory use e.g. add item, remove item
SCR_GUI_Inventory = Procedurally generate inventory UI and update UI
SCR_GUI_Crafting = Procedurally generate Crafting UI
SCR_CraftingInventory = Handles checking for players held materials and crafting fireworks
SCR_CraftingButtons = UI script for crafting fireworks buttons
ItemData = Scriptable Object that holds item info
CraftableData = Scriptable Object that holds recepie info
